# Gangs (BETA)

Teams of AI agents that work for you. Website: https://gangs.run

## Download
Get the latest version from [Releases](../../releases/latest):
- **Mac:** `Gangs_x.y.z_universal.dmg` (Apple silicon and Intel)
- **Windows:** `Gangs_x.y.z_x64-setup.exe`

Gangs updates itself after you install it.

> Windows may show "Windows protected your PC" the first time.
> Choose **More info › Run anyway**. The installer isn't code-signed yet.
